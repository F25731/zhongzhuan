一、先装这 3 个

你的网站教程不用讲复杂原理，先把环境装好就行。大多数用户只要这三样：Node.js、Git、CC-Switch。

1. 安装 Node.js

推荐安装 Node.js LTS 版本。安装完成后，终端里能运行 node -v 和 npm -v 就可以。

下载 Node.js
装完后打开新的终端窗口，输入 node -v 检查是否安装成功。

2. 安装 Git

Git 主要给 Claude Code 和 Codex 在本地项目里工作时用。安装完成后，终端里能运行 git --version 就行。

下载 Git
如果你是 Windows 用户，安装过程一路默认下一步基本就够用。

3. 安装 CC-Switch

CC-Switch 是本地通道管理工具。你需要先装好它，后面首页的一键导入才会弹起并写入 provider 配置。

下载 CC-Switch
如果下载较慢或失败，可以稍后重试，或者联系站点管理员获取最新安装包。

二、从首页一键导入到 CC-Switch

环境装好以后，客户只需要回到首页，输入卡密，选择 Claude 或 Codex 导入即可。

1

打开首页导入页

回到网站首页，进入卡密导入页面，输入你发给客户的卡密。

打开首页导入
2

选择要导入的类型

Claude 用户点 导入 Claude，Codex 用户点 导入 Codex。浏览器弹出“是否打开 CC-Switch”时，选择允许。

3

在 CC-Switch 里确认并激活

导入成功后，回到 CC-Switch，确认已经出现新 provider。如果没有当前使用标识，手动点一下激活。

  • 导入成功：能看到新通道
  • 激活成功：当前通道高亮或显示正在使用
4

客户端和 VS Code 都可以用

只要 CC-Switch 已经导入并激活成功，客户端和 VS Code 里就都可以直接走这条通道，不需要再单独手填 key 和 endpoint。

如果 VS Code 在导入前就已经开着，建议重开一次 VS Code 或者至少新开一个终端窗口。

三、Claude Code 教程

这部分只讲最短路径：安装 CLI、验证命令、在终端里启动。前提是你已经完成上面的环境安装和 CC-Switch 导入。

终端里安装 Claude Code CLI

打开 PowerShell 或 Windows Terminal，执行下面这条命令：

npm install -g @anthropic-ai/claude-code

安装完成后，执行：

claude --version
如果能看到版本号，说明 Claude Code CLI 已经装好了。

怎么开始用

进入你的项目目录后，直接运行：

claude

如果你已经在 CC-Switch 里导入并激活了 Claude 通道，CLI 会直接走这条通道。

  • 客户端：直接打开就能用
  • VS Code：重开窗口后使用 Claude Code / 相关扩展即可
  • 终端：在项目目录运行 claude
如果终端提示找不到 claude 命令，通常是 Node.js 没装好，或者装完后没有重开终端。

四、Codex 教程

Codex 这边同样只保留你真正需要告诉用户的步骤：安装 CLI、验证命令、开始使用。

终端里安装 Codex CLI

打开 PowerShell 或 Windows Terminal，执行下面这条命令：

npm install -g @openai/codex

安装完成后，执行：

codex --version
如果能看到版本号，说明 Codex CLI 已经装好了。

怎么开始用

进入你的项目目录后，直接运行：

codex

如果你已经在 CC-Switch 里导入并激活了 Codex 通道，CLI 会直接走这条通道。

  • 客户端：导入后直接可用
  • VS Code：重开窗口后使用 Codex / 对应插件即可
  • 终端：在项目目录运行 codex
如果终端提示找不到 codex 命令，先检查 node -v、npm -v 是否正常，再重开一个终端。

五、最常见的两个问题

Q1

导入成功了，但终端还是不能用

先确认三件事：

  • Node.js 已装好，node -v 能出版本号
  • CLI 已装好，claude --version 或 codex --version 能出版本号
  • CC-Switch 里对应通道已经激活
Q2

VS Code 里没生效

最常见的原因是 VS Code 在导入前就开着。直接重开 VS Code，或者至少新开一个终端窗口，再试一次。
