使用说明

第一次使用的用户，建议按这个顺序操作，基本不会出错。

1

先安装 Node.js、Git、CC-Switch

这三个装好以后，客户端、VS Code 和 CLI 才能稳定工作。

2

回到首页输入卡密

Claude 用户选择 导入 Claude，Codex 用户选择 导入 Codex。

3

在 CC-Switch 里确认并激活

导入后确认新通道已经出现，并确保当前通道已经激活。

4

按照教程安装 CLI

如果你要在终端里用，再去教程页按 Claude Code 或 Codex 的步骤安装对应 CLI。

详细环境安装、CLI 部署和 VS Code 使用方式，请进入教程页查看。
